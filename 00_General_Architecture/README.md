# 1️⃣ General MCU Architecture — Fundamentals

This module introduces the internal architecture of a microcontroller with clear explanations and simple diagrams.  
You will understand how every subsystem works and how firmware interacts with the hardware.

---

## 📂 Contents

- **Overview of a Microcontroller**
- **Core Components**
  - CPU / ALU
  - Bus system
  - Memories (Flash, SRAM, EEPROM)
  - Peripherals (Timers, UART, ADC, etc.)
  - Clock system
  - Interrupt controller
- **Architecture block diagram**
- **Register-level view**
- **Real-world examples (AVR, STM32, PIC, ESP32)**

---

## 🎯 Learning Goals

By the end of this module, you will be able to:

- Understand what happens inside an MCU.
- Visualize how CPU, memory, and peripherals are connected.
- Read block diagrams from datasheets.
- Identify buses, registers, and memory maps.
- Relate architecture to embedded C code.
